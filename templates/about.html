About the project

Abstract

CineMatch is a web-based movie recommendation system that predicts how much a user will enjoy a movie they have not seen. It combines item-based collaborative filtering with a TF-IDF content-based model into a hybrid recommender, handles the cold-start problem with popularity and favourite genres, explains every suggestion, and is validated with an offline evaluation module.

Algorithms

  1. Popularity - Bayesian weighted rating WR = v/(v+m)·R + m/(v+m)·C so a movie with two 5-star votes does not beat a proven classic.
  2. Content-based - each movie becomes a TF-IDF vector (genres, director, actors, plot words, decade). Similarity is the cosine of two vectors. A rating is predicted from the top 10 most similar movies the user has rated.
  3. Collaborative filtering - adjusted cosine similarity between movies after subtracting each user's mean rating, with significance shrinkage n/(n+5). Prediction: item mean + Σsim·(ruj - meanj) / Σsim.
  4. Hybrid - α·CF + (1-α)·Content with α = n/(n+40), where n is the number of movies the user rated, blended with a user/item bias baseline for stability.

Architecture

Browser (HTML/CSS/JS)
   |  HTTP / JSON
Flask routes (app.py)  -- auth, CSRF, validation
   |                        |
SQLite (database.py)   Recommender (recommender.py)
 users, movies,          popularity, TF-IDF, item-CF,
 ratings                 hybrid, evaluation
   ^
seed_data.py: 70 movies, 60 synthetic users

The model retrains automatically whenever a rating is added, changed or removed.

Key features

  • Registration, login, hashed passwords, CSRF protection
  • Search, genre filter, sorting and pagination
  • One-click 5-star rating with live community averages
  • Four recommendation modes with explanations ("Because you liked...")
  • Rating prediction on every movie page
  • Cold-start handling and graceful fallbacks
  • REST endpoints: /api/recommendations, /api/movies/<id>/similar
  • Evaluation dashboard (RMSE, MAE, Precision, Recall, NDCG)

Future scope

  • Matrix factorisation (SVD / ALS) for larger datasets
  • Import the MovieLens dataset and live posters via a free API
  • Implicit feedback (clicks, watch time) and session-based models
  • Diversity and novelty re-ranking
  • Deployment with Gunicorn and PostgreSQL
